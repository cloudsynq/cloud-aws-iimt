# Recommended Resources — AWS

## Free Official Training
- **AWS Skill Builder** — Free hands-on labs, practice exams, and courses straight from Amazon.  
  👉 https://skillbuilder.aws
- **AWS Free Tier** — 12 months of free access to 100+ services including EC2, S3, RDS, and more.  
  👉 https://aws.amazon.com/free

## YouTube Channels
- **Abhishek Veeramalla** — Hindi/English, beginner to advanced, very practical. Recommended for all topics in this course.  
  Search: `Abhishek Veeramalla AWS` on YouTube
- **TechWorld with Nana** — Clean, visual explanations. Good for Docker, Kubernetes, and DevOps alongside AWS.
- **AWS Official Channel** — re:Invent talks and product demos directly from AWS engineers.

## Practice & Mock Exams
- **Tutorials Dojo** — Best AWS practice questions on the internet. Free sample tests available.  
  👉 https://tutorialsdojo.com
- **ExamTopics** — Large bank of real exam questions. Use for AWS Cloud Practitioner prep.  
  👉 https://www.examtopics.com

## Documentation
- **AWS Docs** — Official reference. Use it to look up any service we cover in class.  
  👉 https://docs.aws.amazon.com
- **AWS Architecture Center** — Real-world reference architectures (good for understanding how everything connects).  
  👉 https://aws.amazon.com/architecture

## If you don't have an AWS account yet
AWS requires a debit/credit card even for the free tier (charged only if you exceed free limits). If that is a problem, speak to the trainer — a shared account can be arranged for lab sessions. Alternatively, use **AWS Skill Builder's browser-based labs** which need no account.
