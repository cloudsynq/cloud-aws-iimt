# Recommended Resources — AWS

## Video

- AWS's own free digital training: https://aws.amazon.com/training/digital/
- Look for beginner-friendly AWS Cloud Practitioner content on YouTube as a companion to class topics — ask in the WhatsApp group if you want a specific recommendation.

## Practice

- AWS Skill Builder (free tier) — hands-on labs and practice questions.

## If you don't have an AWS account yet

AWS requires a card even for the free tier (it is only charged if you go past free-tier limits). If that's a blocker for you, talk to the trainer — a shared or paired account can be arranged for lab sessions.
